# Kit de sensibilisation des agents distributeurs

| Version | Date | Auteur | Modification |
|---|---|---|---|
| 1.0 | 2025-11-05 | Responsable Réseau de distribution | Création |
| 1.1 | 2026-07-01 | Responsable Réseau de distribution, RSSI | Ajout des fiches SIM swap et faux service client |

Ce kit est remis par les superviseurs lors de la session annuelle de 30 minutes (voir le [programme de sensibilisation](programme-sensibilisation.md)). Il est imprimé en format A5 recto verso et existe en français et en anglais. Les phrases sont volontairement courtes.

---

## Fiche 1 - Les 5 règles d'or de l'agent KamaPay

1. **Votre PIN agent est secret.** Personne ne vous le demandera : ni KamaPay, ni votre superviseur, ni un technicien.
2. **Ne faites jamais une opération pour quelqu'un d'autre** avec votre propre compte ou votre téléphone.
3. **Vérifiez la pièce d'identité** pour tout retrait au-dessus du plafond indiqué dans l'application.
4. **Ne fractionnez jamais** une opération pour contourner un plafond. C'est interdit et c'est détecté.
5. **En cas de doute, ne faites pas l'opération** et appelez la ligne agents (option « fraude »).

## Fiche 2 - Reconnaître une tentative de fraude

| Ce que vous voyez | Ce que cela peut cacher | Ce que vous faites |
|---|---|---|
| Un client veut retirer une grosse somme juste après avoir changé de SIM | Compte volé (SIM swap) | Refusez poliment, appelez la ligne agents |
| Plusieurs personnes viennent retirer sur le même compte dans la journée | Compte « mule » | Refusez, notez l'heure, appelez la ligne agents |
| Un client est au téléphone avec un « agent KamaPay » qui lui dicte quoi faire | Escroquerie au faux service client | Dites au client de raccrocher, KamaPay ne fait jamais cela |
| On vous propose une commission pour faire de faux dépôts | Fraude interne | Refusez et signalez ; votre contrat d'agent serait résilié |
| Un appel vous demande votre PIN pour « mettre à jour l'application » | Vol de votre compte agent | Raccrochez, appelez votre superviseur |

## Fiche 3 - Protéger votre téléphone et votre application

- Verrouillez le téléphone avec un code ou une empreinte.
- Installez l'application agent uniquement depuis le magasin officiel.
- Ne prêtez pas votre téléphone d'agent.
- Si le téléphone est perdu ou volé : appelez **immédiatement** la ligne agents pour bloquer le compte agent.
- Si votre SIM ne capte plus le réseau sans raison : appelez la ligne agents, cela peut être un SIM swap sur votre propre ligne.

## Fiche 4 - Comment signaler

1. Appelez la **ligne agents**, choisissez l'option « fraude ».
2. Donnez : votre code agent, l'heure, le numéro du client (si vous l'avez), ce qui s'est passé.
3. N'essayez pas d'arrêter vous-même un fraudeur. Votre sécurité passe avant tout.
4. Gardez le reçu ou la capture d'écran de l'opération.

Un signalement de bonne foi n'est **jamais** sanctionné, même si c'était une fausse alerte. Les agents qui signalent une fraude réelle sont reconnus lors du bilan annuel du réseau.

## Fiche 5 - Ce que KamaPay ne vous demandera jamais

- Votre PIN agent ou le PIN d'un client.
- Un code reçu par SMS.
- D'installer une autre application que l'application agent officielle.
- De faire un dépôt « test » sur un numéro inconnu.

| Durée | Contenu |
|---|---|
| 5 min | Pourquoi la fraude nous concerne tous (exemple : vague de SIM swap de février 2026, comptes vidés et retirés chez des agents) |
| 10 min | Fiches 1 et 2, avec deux mises en situation jouées |
| 5 min | Fiches 3 et 5 |
| 5 min | Fiche 4 : chaque agent enregistre la ligne agents dans son téléphone |
| 5 min | Questions, émargement (la feuille alimente le suivi dans `data/sensibilisation.yaml`) |
